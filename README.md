# SMART CALC — AI INCOME LAB

Демонстрационный калькулятор ориентировочной стоимости ремонта квартиры. Полностью русскоязычный адаптивный интерфейс, мгновенная смета, разбивка по категориям и демо-форма с валидацией.

**Concept / Demo:** проект не представляет действующую ремонтную компанию. Все ставки условные, не являются рыночными ценами или коммерческим предложением. Клиенты, отзывы и результаты бизнеса не заявляются.

## Запуск

Самый простой способ: открыть `index.html` в современном браузере. Для предсказуемой работы буфера обмена рекомендуется локальный сервер:

```sh
cd smart-calc
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8080>. Остановить сервер: `Ctrl+C`. Если порт занят, замените `8080` на `8081` в команде и адресе.

В первой команде используйте имя папки, в которую скачали проект. Абсолютные пути к компьютеру автора для запуска не нужны.

Node.js, установка пакетов, сборка, платные API и внешние шрифты для работы продукта не нужны. HTML, CSS и JavaScript позволяют запустить проект с диска или на любом статическом хостинге. Современные браузеры должны поддерживать `<dialog>`, CSS `:has()` и Unicode-регулярные выражения.

## Возможности

- Площадь от 20 до 200 м²: слайдер и числовое поле, синхронизированные между собой.
- Три типа ремонта: косметический, капитальный, дизайнерский.
- Дополнительные работы: электрика, сантехника, демонтаж.
- Мгновенный итог, формула каждой категории и ориентировочные сроки.
- Сброс к 54 м², капитальному ремонту без дополнительных опций.
- Копирование текстовой сметы вместе с формулами и предупреждением об условных ценах.
- Демо-форма с проверкой имени, телефона и подтверждения демо-режима; состояние успеха.
- Клавиатурная навигация, доступные подписи, сообщения об ошибках и изменения расчёта для скринридера.
- Поддержка уменьшенной анимации, мобильных экранов и высокой плотности пикселей благодаря SVG-плану.

Если числовое поле содержит недопустимое значение, выводится ошибка и сохраняется последняя корректная смета; при уходе из поля последнее корректное значение восстанавливается. Копирование использует Clipboard API и резервный метод для `file://`; если браузер запрещает доступ, интерфейс показывает ошибку, а не ложное подтверждение.

## Прозрачная модель

Все ставки и коэффициенты находятся в `PRICING` в файле `pricing.js`. Для замены ставок редактируется только этот объект. Интерфейс подставляет из него цены карточек и дополнительных опций. Тесты содержат независимые ожидаемые ставки: при согласованном изменении модели обновите их.

| Тип ремонта | Работы, ₽/м² | Материалы, ₽/м² | Дней/м² | Минимум дней |
| --- | ---: | ---: | ---: | ---: |
| Косметический | 4 500 | 3 000 | 0,45 | 14 |
| Капитальный | 8 500 | 5 500 | 0,80 | 25 |
| Дизайнерский | 13 500 | 9 000 | 1,20 | 40 |

| Опция | ₽/м² | Дополнительных дней/м² |
| --- | ---: | ---: |
| Электрика | 1 800 | 0,12 |
| Сантехника | 1 400 | 0,10 |
| Демонтаж | 900 | 0,08 |

```text
Категория = round(площадь × ставка)
Итого = сумма округлённых категорий
Минимальный срок = ceil(max(минимум типа, площадь × дней/м² типа)
                        + площадь × сумма коэффициентов выбранных опций)
Максимальный срок = ceil(минимальный срок × 1,25)
```

Например, 54 м² и капитальный ремонт без опций: 459 000 ₽ работ + 297 000 ₽ материалов = **756 000 ₽**, срок **44–55 дней**. С электрикой: ещё 97 200 ₽, итог **853 200 ₽**, срок **50–63 дня**.

Опции включают соответствующие работы и расходные материалы и не дублируют базовые категории. Мебель, бытовая техника и перепланировка не включены. Это учебная линейная модель, без географии, обследования помещения и параллельного выполнения этапов.

## Демо-форма и данные

Форма не использует `fetch`, XHR, почтовые сервисы, аналитику, cookies, `localStorage` или серверную отправку. Обработчик предотвращает стандартную отправку. Ввод находится только в полях страницы; после успешной проверки или закрытия окна поля очищаются. Используйте вымышленные данные: например, «Алексей», `+7 (999) 123-45-67`.

Имя: 2–60 символов, буквы, пробелы, дефис и апостроф, первая буква обязательна. Телефон: 10 цифр или 11 цифр с первым символом 7/8; разрешены `+`, пробелы, скобки и дефисы. Это проверка формата, а не проверка существования номера.

## Повторение проверок

Для модели нужен Node.js:

```sh
node --test tests/pricing.test.cjs
```

Для браузерного QA установите Playwright как временную зависимость (это не требуется пользователям сайта):

```sh
npm install --no-save playwright
npx playwright install chromium
```

Сначала запустите локальный сервер в отдельном терминале, затем:

```sh
node tests/browser.cjs
```

Опциональные переменные: `TEST_URL`, `PLAYWRIGHT_PATH` (путь к пакету Playwright), `PLAYWRIGHT_BROWSERS_PATH` (каталог браузеров), `BROWSER_EXECUTABLE` (путь к Chromium). Встроенный сценарий ожидает сервер на `127.0.0.1` и проверяет отсутствие внешних запросов. Результаты текущего прогона находятся в `qa/REPORT.md`.

## Бесплатная публикация через GitHub Pages

Проект подготовлен к публикации. Проверка размещения в подпапке `/smart-calc/` описана в `qa/PUBLISH-READINESS.md`. Архив `dist/smart-calc-site.zip` содержит только шесть файлов сайта: извлеките его содержимое в корень репозитория, если хотите опубликовать только демо. Для портфолио с открытым исходным кодом загружайте также документацию и тесты из проекта; архив, зависимости и локальные настройки в Git не нужны.

1. В своём GitHub создайте **публичный** репозиторий, например `smart-calc`. На бесплатном тарифе GitHub Pages работает с публичными репозиториями.
2. Загрузите `index.html`, `styles.css`, `pricing.js`, `app.js`, `favicon.svg`, `.nojekyll` и документацию в корень ветки `main`. Папку `qa/screenshots` можно оставить только локально. Используйте веб-интерфейс GitHub или Git.
3. Откройте **Settings → Pages → Build and deployment**.
4. В **Source** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, затем **Save**.
5. После завершения публикации адрес будет вида `https://ВАШ-ЛОГИН.github.io/smart-calc/`. Относительные пути проекта поддерживают размещение в подпапке.
6. Откройте опубликованный сайт на компьютере и телефоне, проверьте копирование и демо-форму. HTTPS обеспечивает работу Clipboard API, если браузер разрешает доступ.

Инструкция сверена 7 октября 2026 года с [официальной документацией GitHub Pages](https://docs.github.com/en/pages/quickstart). Репозиторий и публичный сайт в рамках этой задачи не создавались. Для внешней публикации требуется отдельное подтверждение владельца.
